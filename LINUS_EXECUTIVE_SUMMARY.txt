   Risk: Log loss, hard to debug issues

   Risk: 5 agents making unlimited calls = budget exposure
   Fix: Set per-agent quotas, OpenRouter spending cap, daily alerts

9. SINGLE POINT OF FAILURE
   Risk: No redundancy = full outage if VPS fails
   Fix: Plan standby replica on different provider

10. NO SSH KEY-ONLY AUTH
    Risk: Weak passwords vulnerable to brute force
    Fix: Disable password auth, require SSH keys

11. NO SWAP SPACE
    Risk: OOM killer terminates processes instead of graceful degradation
    Fix: Add 2-4GB swap
